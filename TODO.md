# Raabta AI — outcome tracker

## Already delivered in the existing app source

- [x] **Raabta identity and compact mobile foundation.** The app is named Raabta AI (رابطہ), uses the original paired-arc brand mark on launcher/splash artwork, and reuses the initialized Expo Router / React Native / TypeScript starter instead of starting from zero. The app has the light ivory/teal palette, local history, one-hand conversation layout, MIT license and public-facing privacy/feature docs; no provider key is hardcoded.
- [x] **Device-only conversation history and truthful task timeline.** Users can start, list, reopen and resume chat threads; thread messages, attachment metadata and local activity events persist on the device. No sign-up, login or cloud chat sync is required. Chat requests send only user/assistant content; local timeline records and secret values are excluded. Successful results and real prepare/retrieve/dispatch/result/failure/stop events are visible without fabricated answers.
- [x] **Public web research and link reading.** A user-triggered DuckDuckGo HTML search returns real public source links, with original URLs/titles stored locally. A public HTTPS HTML/text/JSON/XML page can be fetched, bounded and submitted with a question to the selected model. Login-required pages, PDF/binary parsing and private account browsing are not offered. Failed retrieval produces no invented citations.
- [x] **Image, document and voice input.** The user can select up to four images/readable text, Markdown, CSV, JSON, XML or HTML files and review compact image thumbnails with full-size preview. The original selected image is sent for a vision request. Recording or audio-file selection is explicit, microphone permission is on-demand, audio is capped at 20 MB, the transcript returns to the composer for review and is not sent automatically, and the temporary recording copy is disposed after successful transcription.
- [x] **Public-source Android build automation.** The public GitHub mirror contains the pinned GitHub Actions workflow to install the lockfile, Expo-prebuild Android, run Gradle `assembleRelease`, check the embedded `assets/index.android.bundle` and upload a downloadable APK artifact.
